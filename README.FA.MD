# موچی دسک (Mochi Desk)

موچی دسک یک برنامهٔ گفت‌وگوی هوش مصنوعی برای دسکتاپ است که با پایتون ساخته شده و از API جمنای گوگل استفاده می‌کند. برای استفاده باید از [Google AI Studio](https://aistudio.google.com/app/apikey) کلید API بگیرید و آن را در بخش **Settings** برنامه ذخیره کنید؛ یا کلید را در فایل `ApiToken.txt` قرار دهید.

## امکانات

- **گفت‌وگوی متنی:** می‌توانید چند گفت‌وگو بسازید. تاریخچهٔ بخش متنی به‌صورت محلی در فایل `chats.json` ذخیره می‌شود (تا ۲۰۰ نوبت برای هر گفت‌وگو).
- **گفت‌وگوی صوتی:** با Gemini Live صحبت می‌کنید. زمینهٔ گفت‌وگو تا زمانی که سشن فعال است حفظ می‌شود، اما تاریخچهٔ صوتی پس از پایان سشن به‌عنوان گفت‌وگو ذخیره نمی‌شود.
- **دو ابزار داخلی:** بازکردن برنامهٔ نصب‌شده و اجرای دستور در ترمینال. پیش از اجرای هر دستور ترمینال، برنامه همان دستور را نشان می‌دهد و تأیید شما را می‌گیرد.
- **رابط قابل تنظیم:** انتخاب مدل متنی، تم و اندازه و نوع فونت.

## مدل‌های جمنای

مدل متنی را می‌توانید از منوی بالای صفحهٔ چت انتخاب کنید:

| حالت | شناسهٔ مدل | توضیح |
| --- | --- | --- |
| متن | `gemini-3.5-flash-lite` | مدل پیش‌فرض متن |
| متن | `gemini-3-flash-preview` | مدل متنی قابل انتخاب |
| متن | `gemini-2.5-flash-lite` | مدل متنی قابل انتخاب |
| صوت | `gemini-3.8-live` | مدل گفت‌وگوی زندهٔ صوتی |

دسترسی و موجودبودن مدل‌ها به API گوگل و کلید شما بستگی دارد.

## دریافت و تنظیم API Key

۱. از [Google AI Studio](https://aistudio.google.com/app/apikey) یک کلید API بگیرید.
۲. برنامه را اجرا کنید و کلید را از بخش **Settings** ذخیره کنید؛ یا فایل `ApiToken.txt` را در پوشهٔ پروژه با این قالب بسازید:

```text
api_key=YOUR_GOOGLE_GEMINI_API_KEY
```

کلید را محرمانه نگه دارید. فایل `ApiToken.txt` یا تصویری که کلید در آن دیده می‌شود را در گیت‌هاب منتشر نکنید. این فایل در فهرست فایل‌های نادیده‌گرفته‌شدهٔ Git قرار دارد.

## اجرای پروژه از روی سورس

ابتدا پایتون را روی سیستم نصب کنید. سپس ترمینال را در پوشهٔ پروژه باز کنید و محیط مجازی بسازید.

### مک و لینوکس

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requerments.txt
python run.py
```

### ویندوز PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requerments.txt
python run.py
```

نام فعلی فایل وابستگی‌ها `requerments.txt` است؛ در دستور نصب همین املا را به کار ببرید.

## نکته‌های نصب صدا

کتابخانهٔ PyAudio از PortAudio سیستم استفاده می‌کند. با توجه به سیستم‌عامل، نسخهٔ پایتون و معماری پردازنده، ممکن است pip فایل آماده‌ای پیدا نکند و بخواهد PyAudio را کامپایل کند. اگر نصب خطا داد، مستندات PyAudio و سیستم‌عامل را برای کامپایلر، سرآیندهای توسعهٔ پایتون و بستهٔ توسعهٔ PortAudio بررسی کنید.

برای نمونه، در فدورا نبودن `gcc` می‌تواند خطایی مانند `No such file or directory: 'gcc'` ایجاد کند. وابستگی‌های سیستمی ساخت و صدا را نصب کنید و نصب pip را دوباره انجام دهید:

```bash
sudo dnf install gcc python3-devel portaudio-devel python3-tkinter
```

نام بسته‌ها در توزیع‌های دیگر لینوکس متفاوت است. رابط گرافیکی به Tkinter هم نیاز دارد که ممکن است لازم باشد از مدیر بستهٔ سیستم‌عامل نصب شود. اگر خطای وابستگی بومی دیگری دیدید، متن کامل خطا و مستندات بستهٔ مربوطه را بررسی کنید.

## ابزارها و تأییدها

### بازکردن برنامه

ابزار `open_app` تلاش می‌کند برنامهٔ نصب‌شده‌ای را با نامش اجرا کند. برای این کار از روش متناسب با مک، ویندوز یا لینوکس استفاده می‌کند. برنامه باید نصب و از طریق فهرست برنامه‌های سیستم‌عامل، Start Menu، لانچر یا مسیر اجرایی قابل پیدا کردن باشد. موفقیت ابزار یعنی سیستم‌عامل درخواست اجرا را پذیرفته است؛ این موضوع تضمین نمی‌کند برنامه بعداً چه کاری انجام می‌دهد.

### اجرای دستور ترمینال

ابزار `run_terminal_command` دستور موردنیاز را از پوشهٔ پروژه اجرا می‌کند. پیش از اجرا، خود برنامه دستور دقیق را نمایش می‌دهد و از شما تأیید می‌گیرد. امکان لغو دستور در حال اجرا از داخل رابط وجود دارد. اجرای هر دستور حداکثر ۴۵ ثانیه طول می‌کشد و خروجی آن در چت/بخش فعالیت ابزار نمایش داده می‌شود.

این ابزار ترمینال تعاملی باز نمی‌کند؛ دستور را اجرا و خروجی‌اش را دریافت می‌کند. دستورهایی که منتظر تایپ کاربر می‌مانند—از جمله بسیاری از درخواست‌های رمز `sudo`، نشست تعاملی SSH و ویرایشگرهای متنی—ممکن است خطا بدهند یا timeout شوند. دستورهای دارای دسترسی ویژه یا تعاملی را خودتان در ترمینالی که کنترلش را دارید اجرا کنید. دستوری را که از کارش مطمئن نیستید تأیید نکنید.

## حافظه و حریم خصوصی

گفت‌وگوهای متنی هنگام اجرای سورس در فایل `chats.json` و در پوشهٔ پروژه ذخیره می‌شوند. برنامه سرویس میزبانی تاریخچهٔ چت ندارد؛ اما برای پاسخ به پیام‌های بعدی، زمینهٔ گفت‌وگوی انتخاب‌شده را به API جمنای گوگل می‌فرستد. ذخیرهٔ محلی به معنی رمزگذاری نیست؛ هر کسی که به حساب کاربری سیستم و فایل‌های پروژه دسترسی داشته باشد ممکن است بتواند تاریخچه را بخواند. از رایانه و کلید API خود محافظت کنید.

زمینهٔ گفت‌وگوی صوتی فقط در مدت سشن فعال Gemini Live نگه داشته می‌شود و به‌عنوان تاریخچهٔ چت در `chats.json` ذخیره نمی‌شود. برای انجام گفت‌وگوی صوتی، صدا به API زندهٔ جمنای گوگل فرستاده می‌شود.

فایل `soul` شخصیت موچی و دستورالعمل‌های رفتاری مدل را نگه می‌دارد. **فایل `soul` را ویرایش یا حذف نکنید**؛ مدل از دستورهای داخل آن استفاده می‌کند و تغییرشان ممکن است رفتار برنامه را عوض کند.
